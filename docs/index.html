为什么需要图提取

电商详情页的图片分散在页面各处，一张张右键保存太慢，格式还不统一。图提取把这件事变成一次点击。

图片分散难保存

主图、细节图、场景图散落在长页面里，逐张右键另存费时费力。

格式不统一

原图多为 webp / jpg，素材复用时常需要统一转成 PNG。

批量才高效

一次扫描全部提取，勾选后一键批量下载，自动编号命名。

核心功能

一键提取

自动扫描页面全部商品图，兼容 img、srcset 与各类懒加载属性。

智能过滤

自动排除图标、logo、占位图和小于 100×100 的小图，只留商品图。

集中预览

新页面网格展示所有图片，每张标注真实尺寸，一目了然。

自由勾选

支持全选、反选，按需挑选，实时显示已选数量。

统一 PNG

jpg / webp 自动通过 canvas 转换为 PNG，素材格式统一。

批量下载

一键保存到本地，文件名自动按 商品图_001.png 编号。

四步完成安装

1

下载插件并解压

获取插件压缩包，解压到本地一个固定文件夹，安装过程中不要移动。

2

打开扩展管理页

Chrome 地址栏输入 chrome://extensions 回车进入。

3

开启开发者模式

打开页面右上角的「开发者模式」开关。

4

加载已解压的扩展

点击「加载已解压的扩展程序」，选择解压后的插件文件夹即可。

现在就把商品图一键打包带走

打开任意商品详情页，点击右下角「获取图片」开始。
